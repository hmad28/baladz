# HomeView Specification

## Overview
- Target: `HomeView.tsx`
- Screenshot: `desktop-home.png`
- Interaction: static

## Structure
Centered intro story beside a large campaign image, then repeated two-column visual rows separated by lime rules.

## Styles
- Content max-width: 1160px.
- Intro: two equal columns, heading 22px/800, body 14px/1.7 centered.
- Grid: two equal columns, 18px gap, 18px vertical padding, lime 2px separators.
- Placeholder: pale blue-gray with centered image glyph and `Choose Your Image`.

## Responsive
- <= 760px: single-column stack and full-width visuals.
