# SiteHeader Specification

## Overview
- Target: `SiteHeader.tsx`
- Screenshot: `desktop-home.png`
- Interaction: link hover and click navigation

## Structure
Lime header containing social icons at left, centered Arabic/Latin logo, contact icons at right, followed by three overlapping tabs.

## Styles
- Header: 100% width, 92px desktop, lime background.
- Inner: max-width 1840px, centered, three-column grid.
- Logo: orange-red, centered, condensed uppercase; Arabic line above, small `Pesantren Baladz` label.
- Tabs: white, 52px high, 12px bottom radius; active tab black.
- Icons: 22-28px; generous horizontal spacing.

## Responsive
- Mobile: stacked icon/logo composition, 122px header; tabs scroll horizontally.
