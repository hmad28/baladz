# RegistrationView Specification

## Overview
- Target: `RegistrationView.tsx`
- Screenshot: `desktop-registration.png`
- Interaction: static

## Structure
Long institutional information document with lead heading, square bullets, checkbox bullets, red warnings, headings, paragraphs, and four-column fee table.

## Styles
- Reading width: 920px; left aligned within centered page.
- Body: 14px/1.55, muted gray.
- Headings: 17px/700 with 18-24px top margin.
- Warning: 16px/800, red.
- Bullet/checkbox: 10-12px square.
- Table: full width, compact, borderless.

## Responsive
- Mobile: 15px body, table horizontally scrollable, reading width 100%.
