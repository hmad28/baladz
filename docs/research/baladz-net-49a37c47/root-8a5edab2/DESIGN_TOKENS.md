- Body: 13-15px desktop, 14-16px mobile.
- Section heading: 17-21px, 700.
- Page lead heading: 20-24px, 800.
- Logo: 42-52px, condensed uppercase.

## Layout

- Desktop content width: 1180-1280px.
- Main reading column: 820-920px.
- Header height: approximately 114px including nav overlap.
- Content top gap: 44-58px.
- Footer: full width, 112-132px.

## Responsive

- At <= 900px: two-column content becomes one column; floating poster enters document flow.
- At <= 640px: header icons reduce; navigation remains horizontally scrollable; logo is smaller.
